# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A Claude Code skill plugin that makes Claude respond like a Gen Z person — slang-heavy, high energy, still technically accurate. Activated via `/bro` or natural-language triggers like "talk like a student" / "bro mode" / "speak casual".

## File structure

| File | What it controls |
|------|-----------------|
| `skills/bro/SKILL.md` | **Single source of truth** for all behavior: vocab map, intensity levels, auto-clarity rules, emoji guide. Edit only this file for behavior changes, then `npm run sync`. |
| `hooks/hooks.json` | Wires the hooks into Claude Code when installed as a plugin (`${CLAUDE_PLUGIN_ROOT}` paths). |
| `hooks/gen-z-state.js` | Shared helpers: per-session mode files, stdin JSON, skill loading, hook JSON output. |
| `hooks/gen-z-activate.js` | SessionStart hook — picks the session's mode (resume/compact keep it, startup/clear reset to `GEN_Z_DEFAULT_MODE` or `full`), injects SKILL.md as `additionalContext`, copies the statusline to a stable path, shows a one-time statusline tip as `systemMessage`. |
| `hooks/gen-z-mode-tracker.js` | UserPromptSubmit hook — parses `/bro [lite|full|ultra|off]`, "gen z mode ultra", "stop gen z", "normal mode"; saves the mode and tells the model via `additionalContext`. |
| `hooks/gen-z-statusline.sh` | Reads `session_id` from stdin, prints a colored `[GEN-Z]` / `[GEN-Z:LITE]` / `[GEN-Z:ULTRA]` badge (`GEN_Z_STATUSLINE_COLOR=0` for plain). |
| `hooks/gen-z-settings.js` | Idempotently adds/removes the hooks and statusline in `settings.json` for manual installs. |
| `hooks/install.sh` / `uninstall.sh` | Manual (non-plugin) install into `~/.claude/` and its reversal. |
| `rules/gen-z-activate.md` | Always-on activation rule body for non-hook agents (Cursor, Copilot, Windsurf, Cline). |
| `GEMINI.md` | Gemini CLI context; imports the skill with `@./skills/bro/SKILL.md`. |
| `plugins/gen-z-claude-bro/` | Codex marketplace copy of the skill and Codex manifest. Generated by `npm run sync`; never edit by hand. |
| `scripts/sync.js` | Stamps `package.json`'s version on all manifests and refreshes the Codex copy. `--check` fails on drift (CI). |
| `test/hooks.test.js` | `node:test` suite running the real hooks against a temp `CLAUDE_CONFIG_DIR`. |
| `assets/icon.png` | 512px plugin icon. |

## Hook architecture

```
SessionStart ──writes mode──▶ ~/.claude/gen-z-claude-bro/sessions/<session_id> ◀──writes mode── UserPromptSubmit
                                               │
                                       reads (session_id from stdin)
                                               ▼
                                      gen-z-statusline.sh
                                 [GEN-Z] / [GEN-Z:LITE] / [GEN-Z:ULTRA]
```

State is per session, so "stop gen z" in one terminal doesn't touch the others. Session files older than 7 days are pruned at session start. `~/.claude/.gen-z-active` is still written as a legacy fallback for old statusline setups. All paths honor `CLAUDE_CONFIG_DIR`.

Hooks must **silent-fail on all filesystem errors** — a crash here blocks session start. Keep `require.main === module` guards so tests can import parsers.

## Intensity levels

Three levels defined in `skills/bro/SKILL.md`: `lite` (light slang, no emoji), `full` (default — full Gen Z, 1-2 emoji), `ultra` (maximum chaos). Plus `off`. Persists for the session until changed.

## Slash command

`/bro` (`/gen-z-claude-bro:bro` as a plugin) — activates or switches intensity (`/bro lite|full|ultra|off`). Natural language also triggers: "talk like a student", "bro mode", "speak casual", "use slang", "be my friend". Off with "stop gen z" or "normal mode".

## Development

```sh
npm run sync   # after editing SKILL.md, .codex-plugin/plugin.json or the version in package.json
npm test       # sync --check + hook tests (what CI runs)
claude plugin validate .
```

Release: bump `version` in `package.json`, `npm run sync`, add a `CHANGELOG.md` entry.

## Manual settings.json wiring

`hooks/install.sh` writes this for you:

```json
{
  "hooks": {
    "SessionStart": [
      {"hooks": [{"type": "command", "command": "node \"$HOME/.claude/hooks/gen-z-activate.js\""}]}
    ],
    "UserPromptSubmit": [
      {"hooks": [{"type": "command", "command": "node \"$HOME/.claude/hooks/gen-z-mode-tracker.js\""}]}
    ]
  },
  "statusLine": {
    "type": "command",
    "command": "bash \"$HOME/.claude/hooks/gen-z-statusline.sh\""
  }
}
```
